# Mi Portafolio

Portafolio personal desarrollado durante mi formación como aprendiz del programa de Análisis y Desarrollo de Software (ADSO) del SENA.

## Descripción

Este proyecto presenta información personal, proyectos y habilidades relacionadas con mi proceso de aprendizaje en desarrollo de software.

## Tecnologías

Las principales tecnologías y herramientas utilizadas son:

- HTML
- CSS
- JavaScript
- Python
- Git
- GitHub

## Cómo ver el proyecto

Para visualizar el portafolio, puedes abrir el archivo `index.html` directamente en un navegador web.

También puedes clonar el repositorio utilizando:

```bash
git clone https://github.com/Juanmarin2007/mi-portafolio.git
